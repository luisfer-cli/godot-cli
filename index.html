godot-cli

A terminal-first command line tool for creating, inspecting, and editing Godot 4 projects without opening the Godot editor for repetitive work.

gd project init MyGame
gd scene create Main --root Node2D
gd scene main Main
gd check --godot
gd run

Install

git clone https://github.com/luisfer-cli/godot-cli.git
cd godot-cli
make install

The installer creates ~/.local/bin/gd. Make sure ~/.local/bin is in your PATH.

Typical workflow

mkdir MyGame && cd MyGame

gd project init MyGame
gd scene create Main --root Node2D
gd scene main Main

gd node add Main Player --type CharacterBody2D
gd script create player.gd --extends CharacterBody2D
gd script attach Main Player player.gd

gd input add jump Space
gd map new Level1 32 18
gd map edit Level1
gd map compile Level1 LevelScene

gd check --godot
gd run

Command reference

Project

gd project init <name>
gd project info
gd project setting get <section/key>
gd project setting set <section/key> <value>

Scenes

gd scene create <path> [--root Node2D]
gd scene list
gd scene main <scene>
gd scene edit <scene>

Nodes

gd node add <scene> <name> [--type Node2D]
gd node list <scene>
gd node get <scene> <node> <property>
gd node set <scene> <node> <property> <value>
gd node duplicate <scene> <node> <new_name>
gd node rename <scene> <node> <new_name>
gd node remove <scene> <node>

Scripts and signals

gd script create <path> [--extends Node]
gd script attach <scene> <node> <script>
gd script list
gd signal connect <scene> <signal> <from> <to> <method>

Input and autoloads

gd input add <action> <key>
gd input list
gd input remove <action>
gd autoload add <name> <script>
gd autoload list
gd autoload remove <name>

Run, check, test, export

gd check [--godot [godot]]
gd test
gd export list
gd export run <preset> [output]
gd run [--godot godot]

TUI editors

Scene browser

gd scene edit Main
KeyAction
j/kMove through the node tree
/Search node path
?Help
:w, :q, :wqWrite/quit commands

Use gd node set or Neovim with your .tscn LSP for deeper property editing.

ASCII maps

levels/*.map files are plain grids. . is empty; every other character becomes a placeholder node when compiled.

P#.
..#
gd map new Level1 16 9
gd map check Level1
gd map edit Level1
gd map compile Level1 LevelScene --tile-size 16

Legend

Optional levels/map.legend maps characters to node types:

[legend]
#=StaticBody2D
P=CharacterBody2D

Map editor keys

KeyAction
h/j/k/lMove cursor
printable keySelect tile
p or spacePaint selected tile
uUndo
:w, :q, :wqWrite/quit commands

Godot integration

gd run, gd check --godot, and gd export run call the real Godot binary. Use --godot /path/to/godot if it is not named godot.

gd check --godot
gd run --godot /opt/Godot_v4/godot
gd export run Linux build/game.x86_64

For tests, configure a command in project.godot:

[gd]
test_command=godot --headless --path . --script res://test_runner.gd

Known limits

  • .tscn support is conservative and line-preserving, not a full Godot resource parser.
  • Native TileMap/TileSet editing is not implemented; use ASCII maps or Neovim/Godot for full tileset metadata.
  • The curses TUIs are intentionally small. They are helpers, not an editor clone.
  • Input mapping supports basic keys first.
