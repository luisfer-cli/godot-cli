godot-cli
Workflow Commands GitHub

Godot 4 · terminal-first · no editor required for routine work

Build Godot projects from your shell.

Create scenes, nodes, scripts, inputs, autoloads, ASCII maps, exports, and tiny Vim-ish TUIs without opening the Godot editor for repetitive tasks.

Get the CLI Quickstart 
$ gd project init MyGame
$ gd scene create Main --root Node2D
$ gd node add Main Player --type CharacterBody2D
$ gd script attach Main Player player.gd
$ gd map edit Level1
$ gd check --godot
$ gd run

Quickstart

git clone https://github.com/luisfer-cli/godot-cli.git
cd godot-cli
make install

mkdir MyGame && cd MyGame
gd project init MyGame
gd scene create Main --root Node2D
gd scene main Main
gd run

Scriptable scenes

Add, rename, remove, duplicate, inspect, and edit node properties from deterministic CLI commands.

Vim-ish TUIs

Use gd scene edit and gd map edit for tree browsing and ASCII level editing with familiar movement keys.

Godot when needed

Run gd check --godot, gd run, and exports through the real Godot binary.

ASCII maps

Edit simple levels as plain text, then compile them to placeholder scene nodes.

P#.
..#
gd map new Level1 32 18
gd map edit Level1
gd map compile Level1 LevelScene --tile-size 16

Command groups

  • project init, info, setting get/set
  • scene create, list, main, edit
  • node add, list, get, set, duplicate, rename, remove
  • script create, attach, list
  • map new, list, check, edit, compile
  • run/check/test/export integrate with Godot headless and presets

Not a Godot editor clone

Complex .tscn, .tres, TileSet, and native TileMap work should stay in Neovim with your Godot LSP or in Godot itself. This tool focuses on the boring 80% that should be fast and scriptable.
